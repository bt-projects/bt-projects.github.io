    Technique

    When tackling JavaScript string-based DSA (Data Structures & Algorithms) questions, certain patterns and techniques show up repeatedly. These patterns are not specific to JavaScript but apply well to JS because of its string methods, hash maps (objects/Map), and functional tools.

    Common Patterns & Techniques for Solving JS String DSA Questions

    Here’s a breakdown of the most important ones:

    1. Sliding Window

    Used when you're working with substrings, windows of characters, or consecutive elements.

    🔍 Problem Types
    • Longest substring without repeating characters
    • Minimum/maximum window substring
    • Anagrams in a string

    Key Idea: Use two pointers (left and right) to maintain a window.

    // Example: Longest Substring Without Repeating Characters
let set = new Set();
let left = 0;
let maxLen = 0;

for (let right = 0; right < s.length; right++) {
  while (set.has(s[right])) {
    set.delete(s[left]);
    left++;
  }
  set.add(s[right]);
  maxLen = Math.max(maxLen, right - left + 1);
}

    2. Two Pointers

    Used when comparing parts of a string, palindromes, or doing in-place operations.

    🔍 Problem Types
    • Valid palindrome
    • Reverse a string
    • Compare characters from both ends
    // Example: Valid Palindrome
let left = 0;
let right = s.length - 1;

while (left < right) {
  if (s[left] !== s[right]) return false;
  left++;
  right--;
}
return true;

    3. Hash Map / Frequency Counter

    Used to count character occurrences, detect duplicates, or track frequencies.

    🔍 Problem Types
    • Anagram check
    • Longest substring with at most K distinct characters
    • Character replacement
    // Example: Check if two strings are anagrams
function isAnagram(s, t) {
  if (s.length !== t.length) return false;
  const count = {};

  for (let char of s) {
    count[char] = (count[char] || 0) + 1;
  }

  for (let char of t) {
    if (!count[char]) return false;
    count[char]--;
  }

  return true;
}

    4. Stack-Based Processing

    Used for balanced parentheses, decoding strings, or processing backspaces.

    🔍 Problem Types
    • Valid parentheses
    • Decode string like "3[a2[c]]" → "accaccacc"
    • Backspace string compare
    // Example: Valid Parentheses
let stack = [];

for (let char of s) {
  if (char === "(") stack.push(char);
  else if (char === ")") {
    if (stack.length === 0) return false;
    stack.pop();
  }
}
return stack.length === 0;

    5. Expand Around Center (Palindrome)

    Used for palindromic substrings.

    🔍 Problem Types
    • Longest palindromic substring
    • Count palindromic substrings
    // Example: Longest Palindromic Substring
function expandAroundCenter(s, left, right) {
  while (left >= 0 && right < s.length && s[left] === s[right]) {
    left--;
    right++;
  }
  return right - left - 1;
}

    6. Sorting and Comparing

    Used when order of characters doesn't matter (e.g., checking if two strings are anagrams).

    🔍 Problem Types
    • Group anagrams
    • Sort characters by frequency
    // Example: Group Anagrams
let map = new Map();

for (let word of strs) {
  let sorted = word.split("").sort().join("");
  if (!map.has(sorted)) map.set(sorted, []);
  map.get(sorted).push(word);
}

    7. Greedy Approach

    Used when you want to make optimal choices at each step to build the final result.

    🔍 Problem Types
    • Remove K digits
    • Lexicographically smallest string
    // Example: Remove All Adjacent Duplicates
let stack = [];

for (let char of s) {
  if (stack.length && stack[stack.length - 1] === char) {
    stack.pop();
  } else {
    stack.push(char);
  }
}
return stack.join("");

    8. Dynamic Programming (DP)

    Used for overlapping subproblems — like counting substrings, finding longest subsequence, etc.

    🔍 Problem Types
    • Longest common subsequence
    • Longest palindromic substring
    • Edit distance
    // Example: Longest Common Subsequence
const dp = Array(m + 1)
  .fill()
  .map(() => Array(n + 1).fill(0));

for (let i = 1; i <= m; i++) {
  for (let j = 1; j <= n; j++) {
    if (text1[i - 1] === text2[j - 1]) {
      dp[i][j] = dp[i - 1][j - 1] + 1;
    } else {
      dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
    }
  }
}
