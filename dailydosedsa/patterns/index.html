    Patterns

    Common Patterns for Solving String DSA Problems String problems often involve manipulation, searching, or transformation. The following patterns are frequently used to solve them:

    1. Two-Pointer Technique
    2. Sliding Window
    3. Hash Map / Frequency Counting
    4. String Reversal
    5. Pattern Matching (e.g., KMP, Rabin-Karp)
    6. Palindrome Checking
    7. String Transformation / Parsing
    8. Anagram Grouping
    9. Dynamic Programming (for complex string problems)
    10. Stack for Parentheses or Matching

    I'll demonstrate each pattern with a sample problem and JavaScript solution, focusing on string-specific applications.

    🎯 Beginner Roadmap: Focus on These 4 Patterns First

    These 4 patterns are used not just in string problems, but across many types of problems in JavaScript and general DSA (Data Structures & Algorithms).

    Let’s walk through each one and see where else it applies — beyond strings.

    ✅ 1. Sliding Window

           [Sliding Window]
            ↙      ↘
       [Strings]  [Arrays]
         ↙             ↘
  Longest Substring    Max Sum Subarray (Size K)
  Without Repeats      Longest Subarray w/ Sum < K

    🔄 Used In:

    • Strings: Substrings, anagrams, distinct characters
    • Arrays: Subarrays with sum ≤ K, max average, product, etc.
    💡 Example (Arrays)
    // Max sum of a subarray of size k
function maxSum(nums, k) {
  let sum = 0,
    max = 0;

  for (let i = 0; i < k; i++) sum += nums[i];
  max = sum;

  for (let i = k; i < nums.length; i++) {
    sum += nums[i] - nums[i - k];
    max = Math.max(max, sum);
  }

  return max;
}

    ✅ 2. Two Pointers

            [Two Pointers]
           ↙     ↘
     [Strings]  [Arrays]
       ↙           ↘
  Palindromes     Sorted 2-Sum / Remove Duplicates

    🔄 Used In:

    • Strings: Palindromes, reverse, compare
    • Arrays: Sorted array problems (e.g., 2-sum, remove duplicates)
    • Linked Lists: Detect cycle, reverse list, middle of list
    💡 Example (Arrays)
    // Two Sum (sorted array)
function twoSum(numbers, target) {
  let left = 0,
    right = numbers.length - 1;

  while (left < right) {
    const sum = numbers[left] + numbers[right];
    if (sum === target) return [left + 1, right + 1];
    else if (sum < target) left++;
    else right--;
  }
}

    ✅ 3. Hash Map / Frequency Counter

         [Hash Map / Frequency Counter]
           ↙         ↘
       [Strings]   [Arrays/General]
         ↙               ↘
    Anagram Checks     Find Duplicates / Frequency Sort

    🔄 Used In:

    • Strings: Anagram, character count, duplicates
    • Arrays: Find duplicates, frequency of elements
    • Graphs / Trees: Adjacency lists, visited nodes, memoization
    💡 Example (Arrays)
    // Find first duplicate element
function findDuplicate(arr) {
  const map = new Map();

  for (let num of arr) {
    if (map.has(num)) return num;
    map.set(num, 1);
  }

  return -1;
}

    ✅ 4. Stack for Strings

                 [Stack]
              ↙   ↘
        [Strings] [Arrays]
           ↙          ↘
  Valid Parentheses  Next Greater Element

    🔄 Used In:

    • Strings: Valid parentheses, decoding
    • Arrays: Next greater element, histogram max area
    • Trees: Iterative DFS traversal
    • General: Undo operations, parsing expressions
    💡 Example (Arrays)
    // Next Greater Element
function nextGreater(nums) {
  let stack = [],
    result = Array(nums.length).fill(-1);

  for (let i = 0; i < nums.length; i++) {
    while (stack.length && nums[i] > nums[stack[stack.length - 1]]) {
      let index = stack.pop();
      result[index] = nums[i];
    }
    stack.push(i);
  }

  return result;
}

    🪜 Recommended Learning Order

    Step Pattern Example Problem Why Important
    1️⃣ Sliding Window Longest substring without repeats High-frequency interview topic
    2️⃣ Two Pointers Valid Palindrome Simple logic + good pointer practice
    3️⃣ Hash Map Valid Anagram Teaches frequency counting
    4️⃣ Stack Valid Parentheses, Remove Duplicates Builds understanding of parsing logic

    🧰 Once You're Confident...

    Move on to these intermediate patterns:

    • Expand Around Center (palindromes)
    • Greedy (string optimizations)
    • Dynamic Programming (for longer problems like edit distance)
